```text
  ↓

External Services
  ↓
Response / Action
```

## 🧩 Skills and Connectors

Hermes Agent can extend its capabilities through skills and connectors.

These allow an agent to interact with tools, services, files, and external systems instead of only generating text.

## 🧠 Memory

One important concept explored during this learning module was agent memory.

The memory system allows the agent to maintain useful information across interactions and use that information to provide more contextual responses.

Important concepts explored include:

* User information
* Long-term memory
* Agent instructions
* Session context
* Personalization

## 📄 Important Configuration Files

The learning module covered files such as:

* `SOUL.md` — defines the agent's personality and behavioral instructions
* `USER.md` — contains user-related context
* `MEMORY.md` — stores useful long-term memory
* `AGENTS.md` — provides agent/project instructions

These files help shape how the agent behaves and operates.
